# Recovery-vector initializer

`func_002B7360` is a complete 216-byte C match using modern MWCCPS2 3.0.3
`-O4,p -sdatathreshold 8`. It selects an initial mode byte from state 6,
updates the actor, and on a negative animation flag advances its state,
installs a three-component float vector through the actual three-argument
`func_001830D0` ABI, clears motion words, and selects the signed horizontal
velocity from the orientation halfword.

The initial mode is one conditional expression; this reproduces the native
shared value register and separate zero-value assignment. The earlier
candidate's direct zero store was four bytes shorter and was never credited.
The vector and velocity constants are real float literals with the exact
native values, rather than integer aliases of float bits. No padding or
assembly is used. This recovery adds code only.
