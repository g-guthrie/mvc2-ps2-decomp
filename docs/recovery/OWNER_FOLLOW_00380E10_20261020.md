# Owner-follow state update

The complete 364-byte function at 00380E10 is reconstructed in
`src/owner_follow_00380e10.c` with MWCCPS2 3.0, optimization
`-O4,p -sdatathreshold 8`.

The counter access uses the same manager view as the existing exact
functions in `w184_e.c`: a signed halfword counter array at offset 0x7C.
The state reset assigns zero to the halfword at 0x1C0 and then narrows that
assignment result into the byte at 0x1B2. This reproduces the native zero
mask and store order. Separate constant assignments in the old candidate
had different code generation.

definitions. Float fields use ordinary 1.0f and 2.0f initializers. Every
relocated instruction in the full function matches retail. There is no new
data ownership or data credit; the counter view reuses the established
layout without reconstructing an additional allocation.
