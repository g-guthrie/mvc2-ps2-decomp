# Exact runtime descriptor lookup

`func_0040AAB8` matches all 172 native bytes with EE GCC 2.96 `-O2 -G0`
and SN assembler G0. Root independently replayed the production object.
The G8 draft was shorter and mismatched; it remains uncredited.

The function performs the native name comparison, writes both output words
on each initial path, conditionally logs through the provider's actual
variadic signature, and searches the runtime directory only when its entries
pointer is present. Its two-word output and four-argument parser transfer
come from the native loads, stores and call registers. The existing provider
at `0x0011EB60` is variadic, so the final source uses that true declaration.

A preliminary unmatched source was accidentally included in an unpublished
local checkpoint while a worker was drafting it. It was removed before any
push and was never registered or counted. This final version is independently
compiler-exact, production-wired, and checked by full-image reconstruction.
